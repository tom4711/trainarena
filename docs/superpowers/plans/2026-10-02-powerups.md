# PowerUps v1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship room-configurable player jokers + host arena events on top of the MVP live round, per `docs/superpowers/specs/2026-10-02-powerups-design.md`.

**Architecture:** Server-authoritative state on `GameSession` with a fixed in-code catalog. Hub exposes `UsePowerUp` / `HostArenaEvent` and optional `powerUpConfig` on `CreateRoom`. Clients render inventory/arena UI only; no client-side scoring.

**Tech Stack:** ASP.NET Core net10.0, SignalR, xUnit, existing Razor/static host+player JS.

## Global Constraints

- Spec path: `docs/superpowers/specs/2026-10-02-powerups-design.md` — follow locked decisions verbatim.
- Activation only in `GamePhase.QuestionActive`; player use only before that player has answered.
- Multiplier order: **double then Team-Boost (`floor`)**; wrong/timeout clears pending double with no refund.
- `extra_time`: first use per question extends global `QuestionEndsAtUtc` by 5s once (non-stacking among players); may stack with host `time_plus` (+5 each).
- Shield: ships in catalog; inert until an effect with `IsCompetitiveTargeting` (none in v1.1 host events).
- No Auto-Advance; no DB migration; German UI labels as in spec.
- TDD: failing test → implement → green → commit per task.
- Branch: `cursor/powerups-v11-47f9` (base: `cursor/phase0-scaffold-47f9`).

```csharp
public enum PowerUpId

// PowerUpKind.cs
namespace TrainArena.Game.PowerUps;
public enum PowerUpKind { Player, Host }

// PowerUpCatalog.cs
namespace TrainArena.Game.PowerUps;
public sealed record PowerUpDefinition(PowerUpId Id, PowerUpKind Kind, string DisplayNameDe, bool IsCompetitiveTargeting);
public static class PowerUpCatalog
{
    private static readonly Dictionary<PowerUpId, PowerUpDefinition> Map = new()
    {
        [PowerUpId.FiftyFifty] = new(PowerUpId.FiftyFifty, PowerUpKind.Player, "50/50", false),
        [PowerUpId.Double] = new(PowerUpId.Double, PowerUpKind.Player, "Double", false),
        [PowerUpId.ExtraTime] = new(PowerUpId.ExtraTime, PowerUpKind.Player, "Extra-Zeit", false),
        [PowerUpId.Shield] = new(PowerUpId.Shield, PowerUpKind.Player, "Shield", false),
        [PowerUpId.BoostAll] = new(PowerUpId.BoostAll, PowerUpKind.Host, "Team-Boost", false),
        [PowerUpId.TimePlus] = new(PowerUpId.TimePlus, PowerUpKind.Host, "Zeit +5", false),
    };
    public static PowerUpDefinition Get(PowerUpId id) => Map[id];
    public static IReadOnlyList<PowerUpId> PlayerIds { get; } =
        Map.Values.Where(d => d.Kind == PowerUpKind.Player).Select(d => d.Id).ToList();
}

// PowerUpRoomConfig.cs
namespace TrainArena.Game.PowerUps;
public sealed class PowerUpRoomConfig
{
    public bool Enabled { get; set; } = true;
    public Dictionary<PowerUpId, int> Starter { get; set; } = new();
    public int StreakRewardEvery { get; set; } = 2;
    public List<PowerUpId> StreakRewardPool { get; set; } = new();
    public int MaxStackPerType { get; set; } = 3;
    public bool HostEventsEnabled { get; set; } = true;
    public int MaxHostEventPerQuestion { get; set; } = 1;

    public static PowerUpRoomConfig CreateDefault() => new()
    {
        Enabled = true,
        Starter = new Dictionary<PowerUpId, int>
        {
            [PowerUpId.FiftyFifty] = 1,
            [PowerUpId.Double] = 1,
            [PowerUpId.ExtraTime] = 0,
            [PowerUpId.Shield] = 1,
        },
        StreakRewardEvery = 2,
        StreakRewardPool = PowerUpCatalog.PlayerIds.ToList(),
        MaxStackPerType = 3,
        HostEventsEnabled = true,
        MaxHostEventPerQuestion = 1,
    };

    public string? Validate()
    {
        if (StreakRewardEvery < 0) return "StreakRewardEvery darf nicht negativ sein.";
        if (MaxStackPerType < 1) return "MaxStackPerType muss ≥ 1 sein.";
        if (MaxHostEventPerQuestion < 0) return "MaxHostEventPerQuestion darf nicht negativ sein.";
        foreach (var (id, n) in Starter)
        {
            if (PowerUpCatalog.Get(id).Kind != PowerUpKind.Player) return "Starter nur Spieler-PowerUps.";
            if (n < 0) return "Starter-Anzahl darf nicht negativ sein.";
        }
        return null;
    }
}
```

- [ ] **Step 3: Implement `TryUsePowerUp`**

Logic (under `_gate`):
1. If `!PowerUpConfig.Enabled` → error.
2. Phase must be `QuestionActive`.
3. Resolve player by connection; must be connected.
4. If nickname already in `_answersThisQuestion` → "Already answered".
5. If kind != Player → error.
6. If inventory count < 1 → error.
7. For `{FiftyFifty, Double, ExtraTime}`: if any of `DoubleActive` / `MaskedWrongIndexes != null` / room flag `_playerExtraTimeUsedThisQuestion` already applied **by this player as their self-effect** — spec: max one active self-effect among those three. Track per player: `HasSelfEffect` = DoubleActive || MaskedWrongIndexes != null || `UsedExtraTimeThisQuestion` on player state.
8. Decrement inventory.
9. Apply:
   - FiftyFifty: pick 2 distinct wrong indexes (shuffle 1..3 excluding correct); set on state; return them.
   - Double: `DoubleActive = true`.
   - ExtraTime: if `!_roomExtraTimeExtendedThisQuestion` then `QuestionEndsAtUtc += 5s`, set room flag; always mark player `UsedExtraTimeThisQuestion` (inventory spent even if already extended).
   - Shield: `HasShield = true` (allowed with other self-effect).
10. In `StartQuestion` after clear answers: clear per-player `DoubleActive`, `MaskedWrongIndexes`, `UsedExtraTimeThisQuestion`; clear `_roomExtraTimeExtendedThisQuestion`, `_hostEventsUsedThisQuestion`, `_boostAllActive`; keep `HasShield` across questions until consumed.

Also add `PowerUpUseResult` in same folder.
