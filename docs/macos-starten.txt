TrainArena auf macOS starten
============================

1. ZIP entpacken
2. TrainArena.app per Doppelklick starten
   (signiert + notarized + stapled — kein Gatekeeper-„Papierkorb“-Dialog)
3. Browser: http://127.0.0.1:5175/  (oder LAN-IP)

Falls macOS beim ersten Start noch nachfragt: „Öffnen“.

Apple-Silicon: trainarena-osx-arm64.zip
Intel-Mac:     trainarena-osx-x64.zip

Details: docs/MACOS_SIGNING.md
